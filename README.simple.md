# dsh-composer-ux · 小白版说明

> 这份是给"不想看长文档"的人写的：**每一步只说做什么、点哪里**。
> 想看细节和原理，去 [`README.md`](README.md)（中文全版）或 [`README.en.md`](README.en.md)（英文版）。

## 这是什么

给 **DeepSeek Harness 网页版**（就是你在浏览器里用的那个界面）的输入框加一堆顺手的功能：
发送键怎么按、右键出来什么菜单、常用提示词一键插入、把随手打的提示词交给模型改好再发、
金额和缓存命中直接显示在输入框下面……

一句话：**它不改你的对话，只让输入框变好用。** 所有功能都能单独关掉。

## 三步用上

**第 1 步：装**

在终端里敲（`<你的profile名>` 换成你平时用的那个，比如 `desktop` 或 `web`）：

```sh
dsh plugin --profile <你的profile名> add dsh-composer-ux
```

**第 2 步：重启 DSH**

**必须重启**（关掉 `dsh web` 再开一次），光刷新网页不够。
重启后设置页会多出一项「输入体验」。

**第 3 步：打开设置 → 输入体验**

- 最上面那个「启用输入增强」是**总开关**，默认开着。
- 下面是一张张卡片，**每张卡片的右上角有它自己的开关**，默认基本是关的 —— 想用哪个开哪个。
- 唯一例外：「统计行」（输入框下面那行缓存命中）默认就开着。

> 装完没看到新东西？多半是没重启，或者这一栏的开关没开。见下面「常见问题」。

## 每个功能一句话

| 功能 | 说人话 | 什么时候用得上 |
|---|---|---|
| **键位** | 发送键、换行键随你设（Enter / Ctrl+Enter / 自己按一遍录下来） | 用别的软件习惯了另一种键位 |
| **右键菜单** | 在输入框里右键，出来的是官方那套、浏览器那套、还是这个插件补的 7 项（撤销/重做/剪切/复制/粘贴/删除/全选） | 嫌浏览器右键菜单在输入框里不好用 |
| **快捷指令** | 输入框上方一枚「⚡ 快捷指令」按钮，点开是一个提示词清单，点一下就插进输入框；常写的可以设成"每次发送都自动带上" | 天天重复敲同一段提示词 |
| **优化提示词** | 同上那枚按钮点开 → 点「✨ 优化提示词」→ 模型把你的草稿改好，**一条一条**给你看改了哪儿，改完你可以自己再改，最后点「插入输入框」才替换你的原文 | 打字快但表达糙，或者想让提示词更完整 |
| **OpenCode 请求头** | 自动给 OpenCode 的模型请求加一个它认识的标记，让它在 DSH 里能用 | 你在用 OpenCode（Go）那类路由 |
| **默认终端** | Windows 上把模型用的终端从 PowerShell 换成 Git Bash | 模型敲的命令老是 PowerShell 语法报错 |
| **官方持久终端** | 给模型一套"开了就一直开着"的终端工具 | 官方自带的那几个终端工具 |
| **统计行** | 输入框下面「缓存命中 xx%」显示成三位小数（不再四舍五入到 100%） | 想看缓存到底命中多少 |
| **金额** | 输入框下面一颗小胶囊，显示这次对话大概花了多少钱；点开看明细，还能按模型改高峰/空闲单价 | 想随时知道花了多少 |
| **重启 DSH** | 设置卡片右上角一枚按钮，原地重启（要按两次确认） | 装了新插件不想去终端敲命令 |

## 常见问题

**Q：装完了，怎么什么都没变？**
三件事依次查：① 重启过 DSH 吗（刷新网页不算）；② 设置 → 输入体验 → 总开关开着吗；③ 你要用的那一栏，**卡片右上角的小开关**开了吗（大部分默认是关的）。

**Q：工具行那个「⚡ 快捷指令」按钮不见了？**
它是跟着「快捷指令」这一栏的开关走的：关掉这一栏，按钮就消失（这是设计，不是坏了）。

**Q：点了「优化提示词」没反应？**
- 输入框是空的、或者只敲了个 `/命令` 没有正文 —— 这两种情况会提示你，并且**不发请求**（不花你的钱）。
- 面板里会显示「优化中…（12s）」，那是在等模型，慢慢等。
- 想中断：按 `Esc`（已经生成的那些会**留着**，不会白花）。

**Q：优化完，我的原文怎么没被替换？**
故意的。改成什么样、要不要用，由你点「插入输入框」决定；你飞行期间改了原文，它会再问一次才覆盖（`Ctrl+Z` 可以退回）。

**Q：金额跟我实际看到的不一样？**
金额是按 DeepSeek **官网刊例价**估算的，不是你账户的实扣；高峰/空闲按**每一笔用量发生的时间**判定，不是按你看面板的时间。可以按模型自己填单价（留空＝用官方价）。

**Q：会不会把我的对话传出去？**
不会多传一处：优化走的是**你自己配置的模型路由**（跟聊天同一个出口），不发到别的地方；插件不读、不存、不打你的 API Key。

**Q：怎么卸载？**
```sh
dsh plugin --profile <你的profile名> remove dsh-composer-ux
```
然后重启 DSH。你的设置和快捷指令文件都留在原地（在 `~/.dsh/` 下），需要的话自己删。

## 两个词的小抄

- **工具行**：输入框**里面**最下面那一行小按钮（`+`、权限、技能、模型选择、麦克风、发送）。
- **面板**：点「⚡ 快捷指令」后，从按钮上方弹出来的那一块（分类 + 提示词清单 + 优化入口 + 优化结果框）。
