## ① 结果框持久化 + 重启恢复

- 现状：结果框（`client/optimize-dock.ts` 的状态机）只在内存里；关面板不清空，但**重启即清**。
- 目标：重启/刷新后，上一轮优化结果还在框里。
- 落点：
  - 新 `src/optimize-state.ts`：**纯函数**（形状净化 `sanitizeDockState`）+ 原子写（临时文件 → `rename`）
    + 轮转上限（只留最近 1 份；超过体积上限就整份丢弃而不是截半）
    + **损坏隔离**（读不出来就改名 `<名>.corrupt-<时间戳>.json` 留证据，绝不覆盖）。
  - 新路由：`GET/PUT /composer-ux/optimize-state`，**先过官方信任关卡**（与其余 6 条一致），
    只读/只写这一份状态文件，路径固定，不接受调用方给路径。
  - 客户端：面板挂载时 GET 一次并 `dockReducer({type:'restore'})`；dock 变化时**去抖 PUT**（≤1 次/2s）。
- 设置页：`optimizeKeepDock`（默认 **开**）+ 一个「清空结果框状态」按钮。
- 验收：重启 DSH 后框里仍是上一轮（含条目、成品、丢几条、档位）；状态文件坏掉时隔离并照常启动。
- 隐私边界（用户已确认）：这份文件里**有成品文本**（含你草稿的逐字引文），与 `quick-prompts.json` 同级；
  台账（②）**不含**任何原文。

## ② 逐轮台账（只记元数据）+ `recap` 工具

- 新 `src/optimize-ledger.ts`：把一轮优化的**元数据**拼成一条记录并追加到
  `$DSH_HOME/composer-ux/optimize-log.jsonl`：`at / sessionId / tier / route / draftChars /
  contextTurns / contextChars / items / dropped / droppedReasons / toolRounds / toolCalls / ms / ok / failure`。
  **绝不写原文、成品、引文** —— 只写字数、条数、原因、耗时。
- 轮转：文件超过 `MAX_BYTES`（默认 512 KB）时从**最旧**开始丢（保留文件尾部），并写一条 `rotated` 记录。
  写台账失败**不得影响优化本身**（整段 try/catch + 记一条 console.warn）。
- 新 `scripts/recap.mjs`：`--last N`（默认 20）/ `--json` / `--session <前缀>` / `--clear`，
  表格列：时间、档位、草稿字数、上下文（轮/字）、条目、丢弃、工具、耗时、结果。
- 设置页：显示"最近 N 轮台账"入口 + 「清空台账」。
- 验收：跑几轮优化后 `node scripts/recap.mjs` 能看到行；**grep 台账文件搜不到草稿里的词**（这条要写成测试）。

## ⑤ 优化器只读工具查证（read / glob / grep）

- 默认 **关**；设置页 `optimizeReadTools`。
- 放行条件（三重与）：开关开 ∧ **能解析出本会话工作目录** ∧ 档位不是"关闭"。
- 工具集（宿主侧实现，只读）：`read`（单文件 ≤200 KB，结果 ≤4000 字）、
  `glob`（≤50 命中、≤400 文件、深度 ≤6、跳点文件与重目录）、`grep`（≤40 命中，只回命中行的路径/行号/片段）。
- 围栏：所有路径必须落在会话 cwd 内（`realpath` 后前缀比对，越界**拒绝并记账**）；不做任何写操作；
  轮次硬上限 **3** 轮（每轮 ≤3 次工具调用），总时限 20 秒，超限即停并如实标注"工具轮次被封顶"。
- 宿主侧循环（`src/optimize-tools.ts` + 在优化路由里接线）：
  `llm.stream({ ..., tools })` → 收 `tool-call-delta` / `block-end` → 执行 → 把结果作为工具消息续下一轮 →
  直到模型给出最终 JSON 或触顶。**回落**：任何工具错误/超限都退回"不带工具"的单轮调用，
  台账记下真实发生过的轮次与调用数（不谎报、也不把失败说成"没派工具"）。
- 系统提示词追加一段「只读查证」说明（照上游 `TOOLS_SYSTEM_NOTE` 的写法）：
  查到的**事实**要标明来自工具（`provenance: machine`），**没读到的不要写成事实**；
  逐字引文仍必须出自**用户原话**（工具内容不能当引文依据 —— 这条与我们的会话上下文纪律一致）。
- 验收测试（新增 `test/optimize-tools.mjs`）：
  围栏（`../` 逃逸、绝对路径、符号链接）、各上限、越界拒绝、轮次封顶、
  工具消息装配正确（假 `llm.stream` 驱动整个循环）、回落路径、台账不落原文。
